Marketplace Multi Seller Multi Buyer + Support Reseller System

Admin Marketplace | --:-- | Marketplace, Multi Seller, Reseller | 1 Komentar

Marketplace Multi Seller dan Multi Buyer + Support Reseller System terintegrasi API Rajaongkir mirip Bukalapak, Tokopedia. Sistem ini dibangun dengan mengembangkan platform yang sudah sangat populer di Indonesia. Setiap member yang mendaftar sudah bisa membuat toko / lapaknya sendiri.

Sistem ini juga menyediakan Bonus Referral dan Bonus Reward kepada toko/reseller, besarannya bisa di-set langsung oleh perusahaan.

FITUR LEVEL KONSUMEN :
  • Halaman statis profil perusahaan
  • Video tutorial pemesanan & pembayaran
  • Gallery foto produk perusahaan
  • Halaman testimoni konsumen
  • Keranjang belanja & konfirmasi pembayaran
  • List data pelapak terdekat
  • Chat langsung dengan pelapak
  • History pemesanan dari toko/reseller
FITUR LEVEL PELAPAK/RESELLER :
  • Memantau stok produk
  • Transaksi pembelian / penambahan stok
  • Transaksi penjualan ke konsumen
  • Cek pembayaran konsumen
  • Kelola no rekening pelapak
  • Report keuangan (belanja, penjualan, modal)
  • Report bonus referral dan reward
  • Edit profile dan alamat pelapak
FITUR LEVEL ADMIN :
  • Mengelola penjualan & pembelian
  • Mengelola konsumen
  • Mengelola data toko/reseller/pelapak
  • Akses penuh semua modul marketplace
